# Демо-бот «Запись на пробный урок»

Telegram-бот для учебных центров от [CaravanHouse IT](https://caravanhouse.uz). Сделан по образцу `quiz-bot` и `shop-miniapp`: grammY + TypeScript, данные в JSON на Volume.

**Две роли, как в демо магазина цветов:**
- **ученик** выбирает курс, день и время, оставляет имя и телефон;
- **администратор** получает заявку с кнопками «✅ Подтвердить / 📞 Перезвоню / ❌ Отменить», и ученику приходит ответ.

В демо (`DEMO_MODE=1`, по умолчанию) карточку администратора получает сам ученик, чтобы одним человеком попробовать обе стороны.

**Персонализация по ссылке.** `https://t.me/<бот>?start=<slug>` показывает название и курсы конкретного центра — из того же конфига, что и сайт `https://edu.caravanhouse.uz/<язык>/p/<slug>`.
- Бот читает конфиг через `/api/p/<slug>` на сайте и кеширует его на 5 минут.
- Сами конфиги в этом репозитории не хранятся: они лежат в приватном репозитории CaravanHouse/sales и приватном хранилище сайта.
- Ссылки для каждого центра выдаёт скрипт `npm run demos` в sales.
- Без метки или с неизвестной меткой бот показывает вымышленный центр Zukko Academy.

После подтверждения бот предлагает «Хочу такого бота» — ссылка в бот заявок CaravanHouse IT с меткой `demobot_<slug>`.

## Переменные окружения

Смотрите `.env.example`.

| Переменная | Что это |
| --- | --- |
| `BOT_TOKEN` | Токен от @BotFather. **Только в переменных окружения Railway**, не в коде и не в git |
| `DEMO_MODE` | `1` — демо (по умолчанию), `0` — заявки уходят в `ADMIN_CHAT_ID` |
| `ADMIN_CHAT_ID` | Необязательно: чат администратора, ему доступна `/stats` (сколько раз открывали бота по каждой метке и сколько заявок) |
| `SCHOOLS_API` | Сайт с конфигами, по умолчанию `https://edu.caravanhouse.uz` |
| `LEAD_BOT_URL` | Бот заявок, по умолчанию `https://t.me/CaravanHousebot` |
| `DATA_DIR` | Папка для данных; на Railway — путь Volume, например `/data` |

## Запуск

```bash
npm install
cp .env.example .env   # вставьте BOT_TOKEN
npm run dev
npm test               # проверка диалога без Telegram
```

Railway: сервис в проекте `caravanhouse-demos`, Volume на `/data`, `DATA_DIR=/data`. Деплой — при пуше в `main`, если подключён GitHub Source.
